Reference · v1

Design system, reverse‑engineered from the live site

Every value on this page is copied directly out of public/assets/site.css — the palette, the Manrope/Inter pairing, the 4px spacing scale, the two easing curves. Nothing here is proposed; it documents what geeseproject.com already ships, so a change made here should be made there too.

Source: public/assets/site.css Fonts: Manrope · Inter Base unit: 4px
Extension — v2
Sections 01–10 below are unchanged — reverse-engineered from the live site exactly as in v1. Sections 11 onward are new, proposed components (badges, alerts, tables, modals, admin sidebar nav, etc.) that the marketing site never needed but an app-scale redesign does. Each reuses only the tokens above, plus a small set of new semantic/motion tokens introduced in §11 and flagged everywhere they're used. Nothing here overwrites v1 — verify against real content before shipping any of it.

11Status & semantic colors extension

The source site never needed status colors — no forms, no tables, no course-approval states. An LMS does: enrollment states, payout status, quiz pass/fail, course approval. These four are new, chosen to sit comfortably next to the brand palette (danger reuses the brand red, info reuses brand blue) rather than introducing unrelated hues.
