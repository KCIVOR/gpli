GP Leadership Institute (GPLI) — LMS Landing Page Preview
===========================================================

WHAT THIS IS
------------
A standalone design preview of a landing page for the GP Leadership
Institute LMS. Content is sourced from gpli.io and rebuilt using The
Geese Project's visual design system (colors, type, buttons, spacing).

This package is independent of the geeseproject.com codebase — nothing
here reads from or writes to that site. It's a self-contained mockup
you can open, review, and share on its own.

HOW TO VIEW IT
--------------
Double-click "index.html" to open it in any web browser (Chrome,
Safari, Edge, Firefox). No server, no install, no internet connection
required — all styling and images are bundled in this folder.

WHAT'S INSIDE
-------------
index.html            The landing page itself (fonts/CSS are inlined,
                       Google Fonts load online if available but the
                       page still works fine offline with system fonts)
assets/img/            10 placeholder stock photos used across the page
                       (hero strip, course thumbnails, facilitator
                       avatars) — swap these for real photography before
                       this goes any further than a design review.

STATUS / NOTES FOR THE TEAM
----------------------------
- This is a DESIGN PREVIEW, not a live or deployed page.
- All buttons and nav links (Courses dropdown, Cart, Log In, Join Now,
  Enroll Now, etc.) are placeholders — nothing is wired to a real
  destination or backend yet.
- Cart icon + "Add to Cart" buttons are functional as a UI demo (the
  counter updates), but there's no real shopping cart behind it.
- Content (courses, categories, facilitators, pricing) is illustrative,
  pulled from gpli.io's public homepage — verify and finalize before
  using any of it as final copy.
